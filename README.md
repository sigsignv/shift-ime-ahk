# shift-ime-ahk

## Overview

左 Shift キーを無変換に、右 Shift キーを変換に割り当てる AutoHotkey スクリプトです。

ただし、次の条件を満たす必要があります。

- Shift キーを単独で押したとき
- Shift キーを 200 ミリ秒未満で離したとき

Shift キーと他のキーを同時に押したとき、もしくは Shift キーを 200 ミリ秒以上押し続けたときは、通常の Shift キーとして動作します。

## Requirements

- AutoHotKey v2.0+
